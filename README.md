# Téléchargements Survie SMP

Fichiers publics du modpack et versions du launcher. Les comptes et le panel restent sur le serveur Survie SMP.

Les petits fichiers sont rangés par empreinte SHA-1 ; les gros fichiers et les installeurs sont disponibles dans les Releases. Les mods déjà distribués par Modrinth ou CurseForge restent téléchargés depuis leurs CDN officiels. Les fichiers tiers conservent leurs licences respectives.
